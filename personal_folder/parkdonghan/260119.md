## 2026.01.19 오늘 한 일 정리

### 1) 오늘의 태도/마인드셋 정리

* “돈을 받고 있다 = 프로다”라는 문장이 가장 인상 깊었음.
* **순간순간 간절했는가**를 계속 점검했고, “정성을 담으면 결과가 좋아질 수밖에 없다”는 생각을 붙잡고 있었음.
* 다만 간절함이 아직 선명하게 체감되진 않았고, **정성 + 조급함이 섞인 감정**처럼 느껴져 스스로도 정리 중.
* 이번 프로젝트에서 원하는 건 “그냥 만들고 끝”이 아니라 **실제로 도움이 되는 것**.
  → “도움 됐다”는 말 한마디를 듣고 싶다는 목표가 분명해짐.

### 2) 강은희 교수님 줌 미팅 준비/진행

* **14시까지 질문지 피드백 + 질문 연습** 진행.
* 가장 큰 통찰:

  * 자폐 판단은 **하나의 지표로 결론 내리는 게 아니라 종합 판단**이다.
  * 그래서 진찰도 여러 번 필요하고, **다른 징후(다른 발달/질환)와 구분**도 중요하다.
  * 우리가 고른 4가지 지표는 “선행적으로 하나만 고르는 것”이 아니라 **전부 필요 지표**이며,
  * 각 지표의 조작적 정의는 **교수님께서 언급해 주신 내용 외 관련 논문에서 참고 가능**하다는 방향을 얻음.

---

### 3) 프로젝트 핵심 정리 (오늘의 결론)

* 우리가 다룰 4가지 지표 확정/정렬:

  1. **호명 반응 (Response to Name)**
  2. **시선 맞춤/시선 전환 = 공동주의 (Eye Contact / Joint Attention)**
  3. **모방 (Imitation)**
  4. **상동·반복행동 (Stereotyped / Repetitive Behavior)**
* 이제 다음 단계:

  * 이 4가지에 대해 **AI로 빈도/시간/성공률을 어떻게 뽑아낼지 설계**하는 단계로 넘어감.
* 팀 협업 관점에서:

  * 이번 프로젝트는 **AI가 핵심**이고,
  * AI가 모호하면 프론트/백이 결정을 못 하니, **AI 쪽 정의를 빨리 확정해서 공유하는 게 중요**하다는 인식이 명확해짐.

### 4) 내일 피드백용으로 잡아둔 검사 시나리오 (초안)

1. **호명 반응 검사**

* 시작 → “아이 이름 부르기(총 10회)” 안내
* 아이가 다른 곳을 볼 때 보호자가 호명
* 앱이 시도 횟수 카운트/종료
* 리포트: **10회 중 반응 횟수 + 평균 반응 시간(초)**

2. **시선 맞춤/공동주의 검사**

* 시작 → “아이와 눈 맞추기 / 주의 유도” 안내
* 보호자가 부르거나 가리키며 “저기 봐” 유도, 반복
* 리포트: **시선 맞춤 성공률 + 시선 전환 성공률**

3. **모방 검사**

* 시작 → “동작 따라하기(박수/바이바이/점프 등)” 순서 제시
* 보호자가 동작 시연 → 아이가 따라할 시간 제공 → 반복
* 리포트: **동작(카테고리)별 성공률**

4. **반복행동(참고 지표)**

* 자유놀이/일상 촬영(개입 최소)
* 리포트: **반복행동 빈도 + 총 지속시간** 참고용 제공
