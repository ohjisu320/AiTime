## 1) vi가 뭐야?

- **vi(Visual editor)** 는 유닉스 계열에서 오래전부터 기본으로 제공되던 **터미널 텍스트 편집기**야.
- 장점: 서버/컨테이너/원격환경에 거의 항상 있고, 가볍고 빠름.
- 단점: 처음 쓰면 “왜 입력이 안 되지?” “왜 나가기가 어렵지?” 같은 상황이 생김
    
    → 이유는 **모드 기반 편집** 때문.
    

---

## 2) vim은 뭐야?

- **vim(Vi IMproved)** 은 vi를 확장/개선한 편집기.
- 대부분의 리눅스에서 `vi`라고 쳐도 실제로는 **vim(혹은 vim 호환)** 이 실행되는 경우가 많아.
- vim은 vi 기능 + 추가 기능(문법 하이라이트, 플러그인, 다중탭, 더 강력한 검색/치환 등)을 제공.

> 결론: “vi로 충돌 해결한다”는 말은 실무에서 사실상 vim(혹은 호환 에디터)로 편집한다는 뜻인 경우가 많아.
> 

---

## 3) 왜 vi/vim이 어려워? (핵심: 모드)

vim은 대표적으로 모드가 2개만 기억해도 급해결이 돼:

- **Normal 모드(명령 모드)**: 커서 이동/삭제/복사/저장/종료 같은 “명령”을 함
- **Insert 모드(입력 모드)**: 우리가 아는 “글자 입력”을 함

모드 전환 핵심:

- `i` : Insert 모드로 들어가기 (입력 시작)
- `Esc` : Normal 모드로 돌아오기 (명령할 준비)

## 4) merge 충돌 파일에서 보이는 표시

충돌 나면 보통 파일에 이런 마커가 생겨:

```
<<<<<<< HEAD
내 브랜치 내용
=======
상대 브랜치 내용
>>>>>>> feature/xxx

```

- 해야 할 일: **둘 중 하나를 고르거나 합쳐서** 최종 내용을 만들고
    
    **`<<<<<<<`, `=======`, `>>>>>>>` 라인을 전부 제거**해야 함.

## 5) “충돌 해결할 때” 최소 생존 키 세트

### (1) 저장/종료

- `:w` : 저장
- `:q` : 종료
- `:wq` : 저장하고 종료
- `:q!` : 저장 안 하고 강제 종료 (**나가기 실패할 때 이것부터**)
- `:wq!` : 강제 저장하고 종료(권한/경고 상황에서)

> : 는 “명령줄 모드(Ex 명령)”로 들어간다는 뜻이야.
> 
> 
> 입력 후 Enter로 실행.
> 

### (2) 입력/취소

- `i` : 커서 위치부터 입력
- `a` : 커서 **뒤**부터 입력(append)
- `Esc` : 명령 모드로 복귀
- `u` : 실행 취소(undo)
- `Ctrl + r` : 취소한 거 되돌리기(redo)

### (3) 이동

- `h j k l` : ← ↓ ↑ → (방향키처럼)
- `gg` : 파일 맨 위
- `G` : 파일 맨 아래
- `w` : 다음 단어로 이동
- `b` : 이전 단어로 이동
- `0` : 줄 맨 앞
- `$` : 줄 맨 끝

### (4) 삭제/편집

- `dd` : 현재 줄 삭제
- `dw` : 단어 삭제(커서부터 단어 끝까지)
- `x` : 커서 한 글자 삭제
- `p` : 붙여넣기 (삭제/복사한 것을 커서 아래/뒤에 붙임)

---

## 6) 충돌 마커를 빠르게 찾는 방법

- `/텍스트` : 검색 (예: `/<<<<<<<` 치고 Enter)
- `n` : 다음 검색 결과
- `N` : 이전 검색 결과

**충돌 해결 루틴 예시**

1. `/<<<<<<<` 로 첫 충돌로 점프
2. `n`으로 다음 마커들 확인하면서
3. 불필요한 라인 `dd`로 삭제하거나, 필요한 내용 남기고 합치기
4. 마커 전부 제거했는지 다시 `/<<<<<<<` 검색해서 남은 거 없는지 확인
5. `:wq`

---

## 7) 자주 쓰는 명령어

- 입력 시작: `i`
- 입력 끝: `Esc`
- 줄 삭제: `dd`
- 검색: `/<<<<<<<` → `n`
- 저장 종료: `:wq`
- 저장 없이 강제 종료: `:q!`
