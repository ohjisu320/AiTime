[ 전문가 인터뷰 후기 ]

- 본인은 의사가 아니라, 진료나 진단은 하지 않으나. 자폐 아동의 초기 면담 및 인터뷰 등은 많이 작업하신 바 있다고 답변 가능 영역을 명확하게 말씀해주셨다.
- 몇몇 포인트를 기록해두자면 다음과 같다.
  - 정량적 지표가 매우 도움이 될 것이다. 
  - 진료/대면실에서는 낯선 환경이라 아이가 위축되거나 over액션하는 경우가 분명히 있으며, 그렇지 않더라도 부모가 집에서는 안 그런다며 말하는 경우가 많다. 이런 경우를 예방하기 위해서라도 가정 환경에서의 행동들을 정량화하는 것은 매우 도움이 될 것이다.
  - 상동 행동이 자폐를 "빼박"진단할 수 있는 특징적인 증상이기는 하지만, ADHD와 감별하기 힘들어 AI로 탐지하기에 어려움이 있다. 특히, 12-24개월의 상동행동이 정상 발달 아동과 비교했을 때 유의미한 차이가 있는지를 여쭈어보았을 때 초기 ADHD 와의 감별을 위해서는 행동만으로는 안 되고, 인지 검사 등 별도의 검사를 함께 활용해주어야 한다고 말씀해주셨다. 우리 서비스에서 상동 행동을 포함하지 않은 이유를 설명할 때 강력한 근거가 될 것 같다.
  - 반향어도 강력한 증상이라고 말씀해주셨으나, 자폐 증상 아동의 경우 정상 발달 기준 언어적 발달이 지연될 가능성이 있다고도 말씀해주셨다. 이를 고려하여 13-24 개월의 경우는 반향어는 우리의 분석 대상이 아니라고 종합해볼 수 있다.
  - 의료진의 니즈 뿐 아니라, "comment 가 필요하다"는 부모의 니즈 또한 충족할 수 있다는 측면에서도 우리 서비스의 의의가 있다고 말씀해주셨다.
  - 자극에 대한 모티베이션이 중요하다고도 말씀해주셨다. 즉, 모방행동. 그 중에서는 손 따라하기 / 얼굴 표정따라하기 / 점핑 등 따라하기를 짚어주셨는데, 이를 척도화할 때는 시간, 빈도, 성공률 다 중요하지만. 성공/실패의 기준을 잘 정의하는 것이 중요하다고 말씀해주셨다. 임상적으로는 3-5초 지연되면 모방행동을 실패했다고 판별하니, 이를 설계함에 있어서는 여러 논문을 참고하여 조작적 정의를 잘 정리해야 한다고 말씀해주셨다.
  - 12-23개월을 우리의 대상으로 한 이유에 근거가 될 법한 말씀도 해주셨다. 자폐는 스펙트럼 장애라서, 전형적인 행동 특성을 보이는 아이들부터 시작해서 서비스 범위를 넓혀가야 한다는 조언을 해주신 것인데. 어린 나이에 의심을 한다는 것 자체가 전형적인 증상이 관찰된다는 연구 결과와 이 조언을 결합한다면, 반박의 근거가 있을 듯 하다. 
  - 워딩으로는 `자폐 행동 검사 도구` 정도를 추천해주셨다.

     - [FiftyOne](https://fiftyone.ai/) is an open-source tool facilitating visualization and access to COCO data resources and serves as an evaluation tool for model analysis on COCO. 이라고 한다.

     - FiftyOne also provides methods allowing you to download and visualize specific subsets of the dataset with only the labels and classes that you care about in a couple of lines of code.

       ```
       dataset = fiftyone.zoo.load_zoo_dataset(
           "coco-2017",
           split="validation",
           label_types=["detections", "segmentations"],
           classes=["person", "car"],
           max_samples=50,
       )
       
       # Visualize the dataset in the FiftyOne App
       session = fiftyone.launch_app(dataset)
       ```
