[목] - 금요일에 코딩 하기 전에 미리 공부할 건 뭐가 있을까!

1. 딥러닝 파이프라인 재확인 (비전, 시계열 쪽으로)

   ```mermaid
   graph LR
       A[<b>1. Data Input</b><br/>Raw Data] --> B[<b>2. Pre-processing</b><br/>Noise 제거, 정규화]
       B --> C[<b>3. Model Inference</b><br/>특징 추출 및 예측]
       C --> D[<b>4. Post-processing</b><br/>임계값 필터링, 포맷 변환]
       D --> E[<b>5. Output</b><br/>최종 결과]
   ```

   ```
   - Input(영상/프레임) -> Pre-processing(전처리) -> Model -> Post-processing(후처리) -> Output(좌표/결과값)의 데이터 흐름도를 손으로라도 그리기
   - input 영상 길이 (00초, 0분)
   - data shape : frame 수 * 관절 포인트 수 17개 * x, y 좌표 2개
   ```

   - 예상 파이프라인

     `[영상 처리] → [좌표 추출] → [논리 연산/분석]`

     1. 영상 처리 : `Video.mp4` → `[Image_Frame_1, Image_Frame_2, ...]`

        1. frame extraction
        2. object Detection

     2. 좌표 추출 : `Image_Frame` → `List of [Person_ID, Keypoints(x, y)]`

        1. 이미지에서 사람의 키포인트(관절 17개 추출)
           - img -> 좌표
           - yolov8-pose나 mediapipe 나 뭐 2인 이상 추적 가능한 모델
        2. ID 트래킹
           - 누가 사람 1번 누가 사람 2번

     3. 데이터 정제 및 부모/아이 분류 : `Raw Coordinates` → `Normalized Vector Sequence (Parent_Vec, Child_Vec)`

        1. 누가 부모/아이
           - 관절 벡터(척추 길이, 전체 신장 등)의 평균 길이 계산
           - 몸통 중심을 (0,0), 키를 1로 맞추는 정규화 수행하여 원근법 이슈 보정 필요할 듯.

     4. 행동 유사도 분석

        - 부모의 행동을 아이가 따라했는지 판별

        - 알고리즘 사용 가능 (DTW)

        - 원리는 다시 한 번 공부할 필요 있음. 설명은 다음과 같음.

          ```
          (제미나이)
          Algorithm: DTW (Dynamic Time Warping)
          이유: 부모가 행동한 뒤(t1) 아이가 1초 뒤(t2)에 따라 해도, 혹은 부모보다 느리게 움직여도 **'패턴의 모양'**을 비교해야 하기 때문.
          Process:
          1. 부모의 동작 시퀀스($S_{parent}$)와 아이의 동작 시퀀스($S_{child}$)를 DTW 알고리즘에 입력.
          2. Distance Calculation: 두 동작 사이의 거리가 얼마나 가까운지(유사도) 계산.
          3. Thresholding: 거리값(Distance) < 임계값(Threshold) 이면 "모방 성공" 판정.
          Output: Boolean(Success/Fail), Latency(반응 시간), Similarity Score
          ```
